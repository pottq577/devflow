# Auditor packet

Operate in Auditor mode with an independent mindset.

1. Pin baseline SHA, target SHA, and diff range.
2. Read the relevant PRD, PLAN, WORK, repository rules, and domain extension.
3. Verify repository facts directly; treat prior reports as leads only.
4. Execute the common audit axes and the requested plan/phase/integration scope.
5. Classify every finding using the DevFlow finding taxonomy.
6. Create remediation WORK directly for `CONFIRMED` and `DOCUMENTATION_DRIFT` findings.
7. Create evidence WORK for `EVIDENCE_REQUIRED` findings.
8. Record and block `DECISION_REQUIRED`/`SPEC_DRIFT` items instead of guessing.
9. Respect dependency ordering when creating remediation.
10. Update STATE and run validation.

Closure mode verifies previous findings and regressions; it does not repeat speculative planning.
