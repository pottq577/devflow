# Architect packet

Operate in Architect mode.

1. Read the approved PRD and repository-enforced rules.
2. Record the immutable git baseline SHA.
3. Explore the current codebase before proposing implementation details.
4. Detect PRD ambiguity, repository conflicts, and specification drift.
5. Produce repository-grounded `PLAN.md`.
6. Split implementation into phases and WORK items using the Work Item Contract.
7. Build explicit dependencies and requirement traceability.
8. Record unresolved human decisions in `DECISIONS.md` and STATE.
9. Run DevFlow validation and correct structural errors.
10. Set STATE so `status` can compute the next action.

Do not create separate task Markdown documents or handoff prompts.
